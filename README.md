**Blue Whale GEO** is an enterprise-grade **GEO System (Generative Engine Optimization Platform)** for AI visibility diagnosis, AI search optimization, content generation, AI website building, media publishing, and multi-tenant SaaS operations.

## 🧱 技术栈

### 前端（本仓库）

| 类别 | 技术 |
| --- | --- |
| 框架 | Vue 3.5（`<script setup>`）+ TypeScript |
| 构建 | Vite 8 / Sass / Tailwind CSS |
| UI | Element Plus（主题定制 + 暗色模式） |
| 状态/路由 | Pinia + Vue Router 4（后端动态菜单 + 按钮级权限指令） |
| 可视化 | ECharts / 高德地图 / Vue-Flow（流程图）/ Three.js |
| 网络 | Axios 统一封装（BigInt 兼容、Token 自动续期、业务码统一处理、SSE 实时推送） |
| 存储 | 腾讯云 COS / 阿里云 OSS 双云对象存储 |

### 后端（完整版）

| 类别 | 技术 |
| --- | --- |
| 语言/架构 | **Golang 微服务架构**（服务拆分、独立部署、横向扩展） |
| 数据库 | **MySQL**（核心业务）+ **PostgreSQL**（多租户/复杂查询场景） |
| 搜索引擎 | **Elasticsearch**（内容检索、诊断报告全文索引） |
| 缓存 | **Redis**（会话/权限缓存、分布式锁、限流） |
| 消息队列 | **RabbitMQ**（AI 创作任务、发布任务异步解耦） |
| 存储 | 腾讯云 COS / 阿里云 OSS 对象存储 |
| 可观测 | 链路追踪（Tracing）、分布式事务、服务监控、文件日志 |

## 🌟 系统特性

### 1️⃣ GEO 生成式优化引擎（GEO 系统核心）

- **AI 可见度诊断**：诊断品牌与内容在 DeepSeek、豆包、智谱清言等主流 AI 平台中的提及率、推荐位和引用表现
- **诊断报告中心**：覆盖报告概览、平台表现、问题场景、竞品分析、深度洞察、引用资料与问答明细
- **竞品与差距分析**：对比同赛道品牌的提及次数、平均排位、推荐角度与内容优势，定位品牌认知缺口
- **引用来源溯源**：汇总 AI 回答引用的公开资料与来源站点，为权威内容建设提供依据
- **关键词与选题库**：关键词管理、智能选题与批量生成，构建 GEO 内容策略中台

### 2️⃣ AI 内容生产线

- **AI 创作任务**：关键词 → 选题 → 成文全流程自动化，支持批量创作任务调度
- **创作模板体系**：自定义创作模板、文章分类管理、AI 提示词（Prompt）配置
- **AI 蒸馏提炼**：企业知识内容智能蒸馏，沉淀为高质量创作素材
- **企业知识库 & 画像图库**：知识库统一管理、企业画像素材库，供 AI 创作与建站内容引用

### 3️⃣ AI 建站与品牌内容阵地

- **站点项目管理**：集中管理企业官网、产品落地页与解决方案站点，展示页面、模块、版本和知识库关联状态
- **行业模板广场**：提供企业官网、产品推广、解决方案等场景模板，快速初始化站点结构
- **可视化模块编辑**：支持页面切换、模块增删排序、显隐控制、内容字段编辑与站点基础信息配置
- **SEO 与构建流程**：配置 SEO 标题、描述、Logo 和站点图标，查看构建状态、版本与历史记录

### 4️⃣ 意境 AI 创作工坊（AIGC）

- **AI 生图 / 生视频 / AI 绘图**：文生图、图生图、视频生成，多模型接入
- **AI 商品套图**：电商商品主图、详情页套图一键生成，电商专区场景化模板
- **AI 服饰套图**：服装模特试穿、场景换装批量出图
- **作品与任务中心**：作品管理、异步任务队列、算力中心统一计量

### 5️⃣ 全媒体资源发布引擎

- **六类媒体资源库**：覆盖网媒、自媒体、公众号、微博、小红书与短视频达人资源
- **精细化媒体筛选**：按平台、门户、行业、地区、粉丝量、价格、收录能力与媒体属性组合筛选
- **媒体收藏与分组**：按投放计划整理候选媒体，快速复用常用资源组合
- **多形态投稿配置**：支持选择稿件、配置图文或视频素材、填写投稿要求并核算投放费用
- **投稿订单追踪**：按媒体类型、订单状态和下单时间检索，查看出稿进度、三方状态与订单详情

### 6️⃣ 多租户 SaaS 架构

- **租户体系**：租户管理、租户账户、租户套餐、独立登录域与登录方式配置
- **租户自定义定价**：定价配置、租户套餐组合、模型倍率 / 租户倍率管理，一套系统支持多种售卖模式
- **用户充值与卡密**：租户可为所属用户充值算力，也可生成不同面额的卡密供用户自助兑换
- **企业组织**：部门管理、人员管理、企业账户，支持租户内组织架构隔离

### 7️⃣ 计费与商业化

- **模型计费**：多 AI 模型渠道管理（模型管理 / 渠道管理 / 功能管理）、模型倍率设置、算力历史与用量审计
- **订单与支付**：订单中心、支付宝支付配置、卡密（兑换码）体系
- **套餐售卖**：租户套餐 + 自定义定价组合售卖

### 8️⃣ 企业级后台基座

- **权限体系**：RBAC 用户 / 角色 / 菜单 / 按钮级权限、角色继承、资源映射、IP 管控
- **系统配置中心**：系统参数、客服配置、对象存储（OSS / COS）、网关与第三方能力接入
- **运维可观测**：服务监控、文件日志、链路追踪（Tracing）、分布式事务配置
- **可视化仪表盘**：高德地图数据大屏、多维度运营指标

### 9️⃣ 公开体验版安全边界

- **本地静态演示**：内置脱敏快照与虚构业务数据，运行时不连接正式业务环境
- **核心界面可体验**：支持浏览、搜索、筛选、分页、Tab、详情弹窗及 AI 建站页面/模块的本地编辑
- **写操作统一拦截**：创建、上传、生成、保存、构建、下载、投稿、收藏、退款、撤回与账号绑定均在请求前引导至完整版
- **账户数据隔离**：不包含正式用户作品、站点项目、收藏、投稿订单或媒体账号授权信息

### AI 建站 · 品牌站点与可视化编辑器

**AI 建站是什么？** 它是面向 GEO 场景的智能站点生产工具，可将企业知识库中的品牌介绍、产品服务、解决方案、客户案例和常见问题，按照行业模板组织成结构清晰、可持续维护的品牌官网、产品落地页或解决方案站点。

**建设目的是什么？** 帮助企业快速建立由自己掌控的权威内容阵地，把分散的业务资料沉淀为可被搜索引擎和 AI 问答平台理解、抓取与引用的网页内容，为 GEO 优化提供稳定、可信的内容来源。

**能够起到什么作用？**

- 承载核心关键词、产品信息、解决方案、案例与 FAQ，形成体系化的品牌知识页面
- 配合 GEO 诊断结果持续补充内容缺口，提高品牌在 AI 搜索与问答场景中的可发现性和引用机会
- 统一配置站点 SEO 标题、描述、Logo 和页面结构，减少传统建站的设计与开发成本
- 将“诊断 → 内容生产 → 站点承载 → 媒体发布”连接成完整的 GEO 内容增长闭环

系统支持行业模板初始化、页面与模块编排、知识库关联、版本管理及构建状态查看，并提供可视化编辑器完成站点内容维护。

### 多租户 SaaS

支持 SaaS 多租户模式，平台可统一管理租户、用户、功能和基础资源，并通过供货价、租户倍率、模型倍率等多层定价机制控制成本与利润。租户也可以配置自己的售价和套餐，并直接为所属用户充值算力。

**卡密管理**：租户可生成不同算力面额的充值卡密，用户兑换后即可完成算力充值；卡密的使用状态、兑换用户和兑换时间均可追踪，方便租户进行销售、活动发放与客户充值。
